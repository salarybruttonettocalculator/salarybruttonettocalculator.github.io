Privacy information

Last updated 24 September 2026. This page describes the site with Cloudflare Web Analytics active and advertising inactive.

Calculator inputs

Salary and scientific calculations run in your browser. The calculator does not submit your entries to a server, create a user account, or store the entries in browser storage. Standard hosting services can still process technical data such as an IP address, browser details and request logs when you visit a page.

External links and referrals

Links to banks open their own websites, which apply their own privacy policies. The Wise signup button uses a referral URL. Wise can recognize referrals after you click it, and this site may receive a reward if you create an account through it.

Cookies and preferences

Cloudflare Web Analytics is active on this site. Its browser beacon sends page URL path, country and performance data to Cloudflare so we can see visits, page views and popular pages. Cloudflare says its Web Analytics does not use cookies or local storage and does not track visitors across its customers’ sites. Salary entries and calculator results are not included in the analytics beacon. No advertising cookies or AdSense are active. See the cookie information. Cloudflare’s privacy information. Advertising consent controls and this notice will be updated before ads are enabled where required.

Advertising

Google AdSense is not active on this site. If advertising is added, this notice will be updated to describe its data processing and a suitable consent system will be configured before ads are displayed where required.
